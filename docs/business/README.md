# המודל העסקי של העוזר

בתיקייה הזו נבדק אם העוזר יכול להפוך למוצר לציבור, ואיך: מה הוא עולה, כמה לגבות, למי הוא מיועד ובאיזה סדר לעשות את הצעדים.
התיקייה שייכת לסשן המודל העסקי (ענף `business`). שום דבר כאן אינו ייעוץ פיננסי או משפטי. אלה טיוטות לדיון עם הבעלים.

## סימונים

- **[הנחה]** — מספר או טענה שעוד לא נבדקו. צריך לאמת לפני שמחליטים עליהם.
- **[מקור: …]** — מאיפה זה נלקח ומתי נקרא. מקור משני (בלוג, מחשבון של צד שלישי) מסומן כך, ויש לבדוק אותו מול האתר הרשמי.
- **[ממתין למדידה]** — תלוי בשבועיים של מדידת עלות ה-AI, שהתחילו ב-2026-11-12. הסיכום צפוי בסביבות 2026-11-26.
- **[החלטה]** — מספר שהקוד ישתמש בו (מחיר, מכסה, גבולות של חבילה). הוא נרשם כהצעה ב-`docs/decisions.md`, והמאסטר מחליט אם לקבל.
