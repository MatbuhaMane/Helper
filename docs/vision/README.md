## דרך העבודה (הבעלים, 2026-11-12)

הבעלים כותב פקודות בזמן שהוא עובר על האפליקציה. הסשן **לא מבצע אותן**:
1. מנסח כל פקודה כהוראה למחלקה שאחראית עליה.
2. אוסף את ההוראות ב-`batch.md`.
3. שולח את כל ה-batch רק כשהבעלים אומר "שלח": הודעה אחת לכל מחלקה, ועותק למאסטר.

מה שמשנה כיוון של המוצר עובר קודם אישור במשפט אחד, ונרשם ב-`docs/decisions.md`.
