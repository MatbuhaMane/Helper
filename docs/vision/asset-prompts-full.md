# פרומפטים מלאים לכל התמונות שהבעלים מכין

כל פרומפט כאן שלם: הוא כולל את בלוק הסגנון, ומדביקים אותו כמו שהוא.

- **מצרפים לכל בקשה** את תמונת האוהל `public/assets/tent.webp` כתמונה הראשונה.
- **בבקשות העונות** מצרפים גם את העץ שבחרת, כתמונה השנייה.
- **שם הקובץ** כתוב ליד כל פרומפט. כל הקבצים נכנסים לתיקייה אחת, והחזון מעביר אותה לעיצוב.
- **הרקע לבן,** כדי שהעיצוב יוכל לחתוך. בסצנות שלמות הרקע הוא חלק מהתמונה.
- **תמונות ה"בקרוב"** של הכלים העתידיים (7–14) נשארות אצל העיצוב, ולכן אין להן פרומפט כאן.

הפרומפטים הקצרים, עם ההסברים, נמצאים ב-[asset-prompts.md](asset-prompts.md).
