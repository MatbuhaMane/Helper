# התמונות שהבעלים מכין בעצמו

**החלטה:** הבעלים, 2026-11-14. הבעלים מכין בעצמו את התמונות שבסעיפים א ו-ג. תמונות ה"בקרוב" (סעיף ב) נשארות אצל העיצוב כמו שהן.

## כללים לכל התמונות

- **הסגנון:** ציור יד בסגנון האוהל:
  - קו דיו כהה ואחיד;
  - צבעי אדמה חמים;
  - טקסטורה מצוירת;
  - בלי תאורה ריאליסטית.

  תמונת הסגנון היא `public/assets/tent.webp`.
- **רקע לבן אחיד (#ffffff), ובלי טקסט בתוך התמונה.** העיצוב מסיר את הלבן וחותך, כי מנועי תמונה לא מייצרים שקיפות טוב. הפרומפטים מוכנים ב-[asset-prompts.md](asset-prompts.md).
- **פורמט:** PNG או WebP. העיצוב ממיר, חותך וממקם.
- **המסירה:** כל התמונות בתיקייה אחת. שם כל קובץ מתחיל במספר הפריט, למשל `01-crown-autumn.png`. החזון מעביר את התיקייה לעיצוב.
